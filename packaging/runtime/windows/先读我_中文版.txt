PRIMELOCK GIS - WINDOWS 中文版
================================

快速开始

1. 使用 Windows 资源管理器完整解压 ZIP 文件。
2. 双击“启动_PRIMELOCK_GIS_中文版.bat”。
3. 地图查看器与支持/控制面板将自动打开并建立连接。

本程序无需安装 Python、uv、PowerShell 模块或其他终端软件，也无需
管理员权限及网络连接。请保留应用文件夹中的全部文件。

如需启动英文版，请双击“START_PRIMELOCK_GIS.bat”。英文版与中文版
使用相同的 GIS 算法、默认数据集和项目文件；区别仅在界面语言。

退出程序

在支持/控制面板中按 q，可关闭完整应用。程序正常退出后会恢复原有
终端设置。

启动诊断

如果应用无法启动，请在此文件夹中打开“命令提示符”，然后运行：

    app\PrimelockGIS.exe doctor --language zh-CN

外部数据集

程序支持加载外部 CSV 数据集。在支持/控制面板的管理命令区域输入：

    load dataset C:\完整\路径\数据集.csv

路径可以包含空格或中文字符。卸载程序不会删除用户自行选择的外部
数据集。应用自带的默认数据集为只读资源。

主要操作

- 使用方向键平移地图。
- 使用鼠标左键点击查询要素。
- 按住鼠标左键拖动以平移地图。
- 使用鼠标滚轮缩放地图。
- 调整终端窗口大小可自动重绘。
- 在支持/控制面板中切换点、网格、TIN、等高线和地形着色。

第三方组件的许可信息见“THIRD_PARTY_NOTICES.txt”及
“app\_licenses”文件夹。
