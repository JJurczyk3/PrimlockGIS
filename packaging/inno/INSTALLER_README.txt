PRIMELOCK GIS OPTIONAL WINDOWS INSTALLER
========================================

This is the optional, offline, per-user installer for Primelock GIS.

- No administrator rights, Python, uv, internet access, or separate terminal
  package is required.
- The default install directory is inside your Local Application Data folder.
- The Start menu shortcut opens the complete Viewer + Support / Control
  experience.
- A desktop shortcut is optional and is not selected by default.
- External CSV datasets can remain anywhere you choose. Uninstalling Primelock
  GIS does not delete those datasets.
- Primelock GIS currently creates no persistent logs or configuration. Any
  future per-user state belongs under the user's Local Application Data folder,
  not beside external datasets.

PRIMELOCK GIS WINDOWS 可选安装程序
==================================

这是 Primelock GIS 的离线、按用户安装程序。

- 无需管理员权限、Python、uv、网络连接或额外安装终端软件。
- 默认安装到当前用户的“本地应用数据”目录。
- 开始菜单提供英文版和中文版两个入口；两者使用相同的 GIS 功能与数据。
- 可在安装时选择是否创建英文版或中文版桌面快捷方式。
- 外部 CSV 数据集可存放在用户选择的任意位置；卸载 Primelock GIS 不会
  删除这些数据集。
- Primelock GIS 当前不会保存持久日志或配置。今后的用户配置应存放在
  当前用户的“本地应用数据”目录，而不是外部数据集旁边。
